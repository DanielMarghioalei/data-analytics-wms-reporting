# Data Analytics and Reporting (SQL & MOCA)

This repository showcases examples of SQL and MOCA command structures
used for automated reporting in warehouse management systems (BY WMS Discrete).

The code focuses on:
- Query structure
- Parameterisation
- Reusable patterns
- Error handling
- Reporting logic design

!!!!!All examples are anonymised and use mock schemas and variables.!!!!!
No customer, site, or proprietary data is included.
